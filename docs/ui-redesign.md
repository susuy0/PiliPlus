# PiliPlus 原生 UI 改版

参考用户提供的 `PiliPlus-UI-Redesign.zip`。原型的模拟视频、账号、评论和下载提示没有移入应用；页面继续使用 PiliPlus 的接口和播放器。

## 本次实现

| 页面 / 功能 | 原生改动 |
| --- | --- |
| 全局 | 浅色、深色、OLED 中性色；默认粉色主题；系统字体层级、12dp 卡片、20dp 弹层、输入框与标签样式。保留用户选择的动态取色和自定义颜色。 |
| 主导航 | 64dp Material 导航，600dp 起侧栏；保留自定义导航和悬浮导航。 |
| 首页 | 搜索栏、分类与卡片样式；新增短视频分类和连续观看。官方 Story 接口发现列表使用空种子；进入播放器后始终以选中的视频作为首条。 |
| 首页配置 | 短视频枚举追加到末尾，保持已有分类索引不变。旧配置只迁移一次，之后仍可隐藏或排序。 |
| 竖屏 | 屏幕边缘控制栏、UP 头像 / 关注、可展开标题、视频详情、收藏黄色状态、双击飘心、长按一键三连圆环、48dp 进度触区。 |
| 竖屏评论 | 默认停靠底部 62%；展开 92% 或键盘出现时暂停；仅恢复由面板暂停的播放。平板右侧 380dp。调整同一个播放器的可用尺寸，让画面按实际剩余空间适应；不重新创建解码器。沿用真实评论、排序、楼中楼与发表评论。 |
| 竖屏更多 | 倍速、画质、字幕、弹幕、会话内适应 / 裁剪填充、稍后再看、投币、收藏夹、离线、复制链接、举报、完整播放器设置；复用原有操作。每次换条重置适应，离开恢复原来的比例偏好。 |
| 视频详情 | 操作行图标 / 字号 / 点击区域统一；原分 P、合集、弹幕、评论和分享保持原有逻辑。 |
| 我的 | 资料卡、统计字号、快捷工具卡和真实列表预览。 |
| 设置 | 五组任务入口，旧设置项目全部保留；搜索结果增加组别路径并可直接操作原设置控件。 |
| 其他页面 | 使用公共主题与组件，保留动态、直播、番剧、消息、登录、收藏、历史、下载等业务页面。 |

## 明确未在这一版扩展的范围

- 原型中标为“后续开发”的自动播放下一条、快速连续滑动请求抢占、返回详情后恢复整段流、PiP 面板状态恢复。
- 对其他业务页面逐一重排所有专用布局，以及统一的列表批量管理容器，仍沿用原来的原生布局和操作。
- Story 不感兴趣理由菜单和断网 / 恢复提示胶囊没有新增。推荐失败与播放失败仍可重试、跳过或返回详情。
- 进度条直接复用原源码 `audio_video_progress_bar.dart` 的 `ProgressBar`，接入原播放器的拖动、缩略预览与毫秒跳转；包含缓冲进度。取消拖动会释放寻址状态，非活动页变为活动页时同步更新原组件手势。

## 翻页交互修正

- 视频、作者、标题、操作栏、进度条和顶部按钮随同一页面整体滑入、滑出。
- 松手吸附停稳后才切换播放；跨过中线再拖回不换片。
- 相邻页提前构建封面与信息，视频和控件跟随页面上下滑动。原生视频纹理保持不透明，避免整层 Opacity 引起离屏混合；关闭过滚动发光与拉伸效果。
- 离开页的互动状态与进度随观看队列缓存和清理。
- 相邻页及加载中的进度条只使用静态快照，不创建没有 Rx 依赖的 `Obx`。旧写法在构建下一页时触发 GetX 异常，正式版 `RenderErrorBox` 以 `0xF0C0C0C0` 灰色覆盖整页；录屏的约 181 灰度及左右 12dp 边距与此一致。进度条高度限制现位于观察器外层，测试同时复现旧错误的整页尺寸、灰色像素，并验证修复后的静态、加载、播放、返回及翻页状态。没有修改全局错误组件或隐藏异常。

## 桌面连续观看与小窗

- Mac、Windows、Linux 与手机共用连续推荐流；Story 入口包含横竖视频，桌面默认保持窗口模式。
- 主窗口内容最大宽度 1100dp，评论停靠右侧；窄窗口使用底部评论。小窗口缩小操作栏。
- 鼠标滚轮一次连续滚动只换一条；触控板与鼠标拖动跟手翻页。
- ↑ / ↓、PageUp / PageDown 切换；空格暂停；← / → 跳转 10 秒；Shift + ↑ / ↓ 调音量；M 静音；F 全屏；P 小窗；C 评论；L 点赞；E 收藏；O 更多；V 详情；H 帮助；Esc 收起面板或还原 / 退出。
- 输入评论时不触发播放快捷键；Command / Control / Option 快捷键不被截获。
- 小窗保留播放器与推荐队列，可拖动、自由调整尺寸、置顶、切换、暂停及静音。还原时恢复窗口位置、尺寸、此前置顶状态与评论 / 标题面板；从全屏进入小窗后还原回全屏。
- Mac 构建运行静态检查、分页及桌面组件测试。原生窗口移动、全屏动画、置顶及真实解码仍需在 Mac 上实际试用验证。

## macOS / iOS 打包

GitHub Actions 选择 `Build for Mac` 或 `Build for iOS` → `Run workflow` → 分支 `vertical-feed`。成功后在该次运行的 Artifacts 下载 `macOS-release`（DMG）或 `iOS-release`（IPA）。项目已有的流程负责 Flutter 安装及必要补丁，无需在本机搭建开发环境。

iOS 当前流程使用 `--no-codesign` 编译并封装 IPA，未配 Apple 分发签名。可用已安装的、兼容系统版本的 TrollStore 安装，或自行重签后安装；TestFlight / App Store 需要开发者分发签名。macOS 当前流程没有 Developer ID 签名与公证。

## 验证

下一条视频预加载：在当前播放稳定且有至少约一秒缓冲时，预取下一条的播放地址，并创建一个静音、暂停的备用播放器，提前缓冲音视频（实际缓冲至少三秒（不足三秒的短片需缓冲到结尾），demuxer 上限 32 MiB）。匹配音视频 URL、编码与音频配置后，切换播放直接接管备用资源，恢复当前音量和正常缓存配置；不匹配、超时或失败走原有打开流程。只保留一条备用，元数据和备用资源最多保留五分钟；离开推荐流、进入后台、内存压力、关闭功能或 Wi-Fi 切换到移动网络时取消备用加载。iOS 系统画中画与 Mac 小窗继续由当前播放器管理。

播放设置新增「下一条视频预加载」：默认仅 Wi-Fi / 有线网络，可选择关闭或所有网络。预加载不提交观看心跳、点赞或关注动作，不使用第二个后台播放会话。`tool/check_feed_preload.dart` 验证资源接管、去重、快速切换、资源匹配、取消、错误恢复与过期释放。真实设备的切换耗时、内存和画中画仍需装机确认。

连续流修复：封面缺失、加载和失败状态统一使用不透明纯黑底，封面加载不交叉淡化浅色占位；取消原生播放器整层淡入，保留页面跟手滑动过渡。导航与弹幕共用安全区计算，即使全屏隐藏状态栏，也保留刘海 / 灵动岛高度；弹幕从导航下方开始并裁剪在实际可用区域内，弹幕点击坐标同步修正。小窗使用其标题栏高度，系统画中画保留原有布局。

关注按钮参考 B 站 Story 实机截图的昵称旁粉色胶囊布局（华安证券 2023-02-23 报告图 64），保留至少 44dp 点击范围。支持已关注、互相关注及特别关注状态，隐藏自己的关注按钮；请求期间禁止重复提交，旧请求不覆盖另一作者的关系状态，同一作者的关系在推荐队列内共享。

- `dart tool/check_vertical_feed.dart`：七项分页 / 并发 / 去重 / 错误 / 生命周期 / 长时间观看检查。
- `flutter analyze --no-pub --no-fatal-infos`：云端完整静态检查。
- `flutter test --no-pub tool/ui_redesign_test.dart`：文字对比度、评论暂停策略、360 / 430 / 840dp 停靠布局、分页位置保持和播放器生命周期；使用播放器替身与原生控件，不代表真实设备解码和账号交互测试。
- CI 输出原生组件预览与 arm64 Android APK。真实解码、系统小窗、登录和发评论仍需在设备验证。
- 本版 APK 使用开发签名。已核对本版与上一版测试包的证书不同，不能直接覆盖安装；卸载前应备份需保留的本地数据。构建机器生成的签名不固定，后续测试包仍需逐次核对，不能承诺覆盖安装。

UP 主连续流：主页投稿卡片和投稿列表的视频进入该 UP 的视频流；推荐流新增「UP主视频」入口。使用原 `MemberHttp.spaceArchive` 与 archive/next 游标，先播放点击的视频，再按最新投稿分页加载该 UP 的全部视频（重复的点击视频会被去重），横竖屏均可播放；不混入推荐接口结果。左上角退出，原推荐队列与位置保留，切回原视频恢复进入时的播放时间。投稿看完后显示退出按钮，不持续请求同一游标。系统返回键和桌面 Esc 走同一退出逻辑；桌面小窗也使用当前 UP 队列。`tool/check_author_feed.dart` 检查游标重试、过滤、去重及终止。

预加载完成须同时满足前三秒实际缓冲与首帧渲染；接管临近完成的备用播放器最多等待 350ms，慢请求继续走正常播放。短视频切换从零开始，避免原详情页的观看历史跳转丢弃前段缓冲；普通详情页保留历史进度。缓冲、首帧、接口或网络异常不阻塞当前视频。32 MiB 仅限 demuxer 前向缓存，不包含解码器和纹理内存。
